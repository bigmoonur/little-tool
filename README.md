# little-tool

- [链接抽取工具](素材抽出工具/README.md)：按分类抽取文本并复制。
- [视频分发工具](视频随机提取工具/README.md)：按分类抽取视频并安全复制到目标文件夹。
- [共享授权模块](shared/license/README.md)：两款工具共用 Keygen 配置、签名校验、离线宽限和 Windows 状态保护。

请保留完整的仓库目录结构。两个 Go 应用通过本地 `replace` 引用 `shared/license`，两款工具改名后都保留原来的源代码目录和数据目录，以兼容已有用户。

两款工具均为启动时联网验证，运行期间每 24 小时复核；离线宽限最多 7 天，不能超过授权到期。同一授权码在同一电脑上共用一个设备名额，缓存各自保存。

两个目录的 `build.sh` / `build.ps1` 使用相同发布参数，默认关闭 Garble，始终启用 `production`、移除调试符号和本机路径。GitHub Actions 支持检查和打包两个工具；本次代码更新不触发打包。
