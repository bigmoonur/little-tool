# 视频分发工具 使用说明

从按分类整理好的视频素材里，每类随机抽几个，复制到目标文件夹，交给处理程序使用。原素材始终保留。

适用于 Windows 10 / 11（64 位）。


## 一、安装

两种方式任选一种：

- 安装版：双击「视频分发工具-版本号-安装包.exe」，按提示完成。不需要管理员权限，桌面和开始菜单会出现「视频分发工具」。
- 免安装版：直接双击「视频分发工具.exe」运行，可以放在任意文件夹。

第一次打开时如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。


### 激活

第一次打开需要输入购买时获得的授权码并联网激活。同一授权码可以用于链接抽取工具，两款工具在同一电脑上共用设备名额，首次使用时分别输入一次。

- 以后每次启动自动联网验证，连续运行每 24 小时复核一次。
- 暂时断网时，从上次验证成功起最多可以继续使用 7 天，但不能超过授权到期时间。
- 「设置 → 授权」可以查看有效期、重新验证或解除本机授权。换电脑前请在两款工具中都解除授权。
- 授权需要重新验证时会保留已填写的数量；已经开始的复制可以继续完成或取消。


## 二、准备文件夹

    D:\视频素材\             ← 素材根目录
        开场\                ← 每个子文件夹是一个分类
            视频1.mp4
            视频2.mp4
        产品展示\
            展示1.mp4
        结尾\
            结尾1.mp4

    D:\待处理\               ← 目标根目录
        第一批\              ← 抽到的视频放进这里的一个文件夹

- 只读取分类文件夹里直接放着的视频；更深的子文件夹、直接放在素材根目录里的视频都不参与抽取。
- 素材根目录和目标根目录必须是两个独立的文件夹，不能相同或互相包含。

第一次打开程序时会依次让你选择这两个文件夹，以后会自动记住。需要更换时：素材根目录在左上角点「更换」，目标根目录在右侧「放入文件夹」旁边点它的名字。


## 三、抽取并复制

1. 在左侧为每个分类填写要抽几个视频。留空或 0 表示跳过。需要把同一个视频多放几份时，再填「乘数」（见下面的“乘数和乘数规则”）。
2. 在右侧「放入文件夹」里选择一个文件夹，或点「新建」并命名。
3. 点「抽取并复制」。

键盘操作：

- 在数量栏按回车跳到下一个分类，最后一个分类按回车直接开始
- Ctrl + 回车：随时开始
- 方向键 上/下：在分类之间移动

复制时会显示进度，可以随时「取消」，取消后目标文件夹恢复原样。完成后右侧列出放入的视频，可以「打开文件夹」检查。

在资源管理器里增减了视频后，切回程序窗口会自动刷新，也可以点左上角的刷新按钮。

### 乘数和乘数规则

| 填写 | 结果 |
| --- | --- |
| 数量 5 | 随机抽 5 个视频，各复制一份 |
| 数量 5，乘数 3 | 按选中的乘数规则放进去 15 个文件 |
| 数量栏直接输入 5*3 | 自动拆成数量 5、乘数 3（也支持 5x3、5×3） |

表格上方可以切换两种乘数规则，点旁边的问号有图示：

- 重复同一批：抽 5 个不同的视频，每个复制 3 份。
- 分轮随机：一共抽 3 轮，每轮重新抽 5 个。同一轮里不重复，不同轮可能抽到同一个视频，也可能抽到新的。

同一个视频的第一份用原来的文件名，其余的副本会在文件名后面加上随机字符，例如「开场1_k.mp4」，内容完全相同。乘数最多 99，一次最多放进去 10,000 个文件。

### 方案

经常用同一组参数时，点「方案」→「把当前数量保存为方案」，起个名字。方案会保存每个分类的数量、乘数和乘数规则，以后在「方案」里点一下就能填入。「管理方案」里可以重命名或删除。

### 用标签找分类

分类多了以后，可以给分类贴标签。点分类名称后面的「+ 标签」，点一下标签就贴上，再点一下取下，不用另外保存；也可以在这里直接新建标签。每个分类的标签会显示在名称后面。

贴过标签后，表格上方会出现标签栏：点一个标签，就只显示带这个标签的分类；可以点多个，带其中任意一个标签的分类都会显示。点「全部」恢复显示所有分类。已经填了数量的分类不会被隐藏。

- 标签只是帮忙找分类，不影响抽到哪些视频。
- 标签按分类文件夹的名称记录；在资源管理器里给分类文件夹改名后，需要重新贴一次。
- 标签栏右边的齿轮可以改名、换颜色或删除标签；删除标签不会动分类和视频。


## 四、规则

- 每个分类内随机抽取，不重复；不同批次可以抽到同一个视频。
- 视频保留原文件名和内容复制过去，原素材不会被移动或修改。
- 同一批视频要放进同一个文件夹，所以会自动避开同名的视频：与其他分类抽中的视频同名的、与目标文件夹里已有文件同名的（大小写不同也算同名）。可用的视频不够时会提示最多还能抽几个，不会覆盖任何文件。
- 支持的格式：.mp4 .mov .mkv .avi .wmv .flv .webm .m4v .mpeg .mpg .ts .mts .m2ts .3gp（按扩展名识别，不检查编码）。
- 复制前会检查目标磁盘的剩余空间。


## 五、清空旧视频

目标文件夹里已有视频时，右侧会出现「复制前清空这里的 N 个旧视频」。勾选后开始复制会先确认，再删除这些旧视频、放入新视频。

- 只删除这个文件夹里直接放着的视频；其他文件和子文件夹保留。
- 请在处理程序停止使用这个文件夹后再操作。
- 完成后这个选项会自动取消勾选。


## 六、复制的安全措施

- 先把全部视频复制到目标根目录里的临时文件夹（.video-picker-开头，已隐藏），全部成功后才一次性放进目标文件夹。
- 复制失败或取消时，撤销本次放入的视频，并恢复被清空的旧视频。
- 复制期间如果目标文件夹被其他程序改动，会停止并恢复，避免和处理程序冲突。
- 意外断电或强制结束程序时可能留下临时文件夹。下次打开会在左侧顶部提示，其中 old 子文件夹可能存有旧视频，确认后可以手动删除。


## 七、复制记录

「记录」页保存最近 50 次复制：时间、用的数量和乘数、放入的文件夹、每个视频的名称和大小。点「打开文件夹」可以直接打开当时的目标文件夹。

- 按这组参数再抽一次：把当时的数量、乘数和乘数规则填回抽取页，再点「抽取并复制」就是新的一批。
- 保存为方案：给这一次的参数起个名字固定下来，以后在抽取页的「方案」里一键填入。


## 八、设置

右上角齿轮图标：

- 窗口始终显示在最前面（右上角的图钉按钮也可以切换）
- 外观：跟随系统 / 浅色 / 深色
- 复制完成后自动打开目标文件夹
- 下次打开时保留上次填写的数量
- 打开数据文件夹

### 锁屏密码

在「设置 → 锁屏」里勾选「打开软件时需要输入 4 位密码」，设置一个 4 位数字密码。开启后：

- 每次打开软件先看到锁屏，输对密码才能使用。
- 顶栏会多一个锁的按钮，点一下可以随时锁定。
- 连续输错 5 次后需要等一会儿才能再试，再输错等待时间会加长，最长 10 分钟。
- 忘记密码时，在锁屏上点「忘记密码？」，输入购买时的授权码就可以关闭锁屏密码，之后在设置里重新设置。

锁屏只是防止别人随手打开软件，不会加密数据文件；数据文件夹里的内容和以前一样。


## 九、数据保存在哪里

    %APPDATA%\VideoRandomPicker\

- settings.json：选择过的文件夹和设置
- lock.json：锁屏密码的校验信息（不保存密码本身）；删除这个文件等于关闭锁屏密码
- tags.json：标签和每个分类贴的标签
- history.json：复制记录
- presets.json：保存的方案
- window.json：窗口大小
- license.json：本机授权信息
- license-state.bin：本机授权保护状态

这些文件不会混进视频文件夹。卸载程序不会删除它们。

便携模式：在「视频分发工具.exe」所在的文件夹里新建一个名为 data 的文件夹，程序就会把数据保存在这里。


## 十、快捷键

| 按键 | 作用 |
| --- | --- |
| 回车 | 数量栏：下一个分类；最后一个分类直接开始 |
| Ctrl + 回车 | 开始抽取并复制 |
| Ctrl + 1 / 2 | 切换到 抽取 / 记录 |
| Esc | 关闭弹窗 |
