# 视频分发工具 使用说明

从按分类整理好的视频素材里，每类随机抽几个，复制到目标文件夹，交给处理程序使用。抽取复制保留原素材；素材库里可以另行确认删除视频。

适用于 Windows 10 / 11（64 位）。


## 一、安装

两种方式任选一种：

- 安装版：双击「视频分发工具-版本号-安装包.exe」，按提示完成。不需要管理员权限，桌面和开始菜单会出现「视频分发工具」。
- 免安装版：直接双击「视频分发工具.exe」运行，可以放在任意文件夹。

第一次打开时如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。


### 激活

第一次打开需要输入购买时获得的授权码并联网激活。同一授权码可以用于链接抽取工具，两款工具在同一电脑上共用设备名额，首次使用时分别输入一次。

- 以后每次启动自动联网验证，连续运行每 24 小时复核一次。
- 暂时断网时，从上次验证成功起最多可以继续使用 7 天，但不能超过授权到期时间。
- 「设置 → 授权」可以查看有效期、重新验证或解除本机授权。换电脑前请在两款工具中都解除授权。
- 授权需要重新验证时会保留已填写的数量；已经开始的复制可以继续完成或取消。


## 二、准备文件夹

    D:\视频素材\             ← 素材根目录
        开场\                ← 每个子文件夹是一个分类
            视频1.mp4
            视频2.mp4
        产品展示\
            展示1.mp4
        结尾\
            结尾1.mp4

    D:\待处理\               ← 目标根目录
        第一批\              ← 抽到的视频放进这里的一个文件夹

- 只读取分类文件夹里直接放着的视频；更深的子文件夹、直接放在素材根目录里的视频都不参与抽取。
- 素材根目录和目标根目录必须是两个独立的文件夹，不能相同或互相包含。

分类和视频可以像上面这样直接在资源管理器里准备，也可以在程序的「素材库」页里新建分类、添加视频。

第一次打开程序时会依次让你选择这两个文件夹，以后会自动记住。需要更换时：素材根目录在左上角点「更换」，目标根目录在右侧「放入文件夹」旁边点它的名字。


## 三、抽取并复制

1. 在左侧为每个分类填写要抽几个视频。留空或 0 表示跳过。需要把同一个视频多放几份时，再填「乘数」（见下面的“乘数和乘数规则”）。
2. 在右侧「放入文件夹」里选择一个文件夹，或点「新建」并命名。
3. 点「抽取并复制」。

键盘操作：

- 在数量栏按回车跳到下一个分类，最后一个分类按回车直接开始
- Ctrl + 回车：随时开始
- 方向键 上/下：在分类之间移动

复制时会显示进度，可以随时「取消」，取消后目标文件夹恢复原样。完成后右侧列出放入的视频，可以「打开文件夹」检查。

在资源管理器里增减了视频后，切回程序窗口会自动刷新，也可以点左上角的刷新按钮。

### 乘数和乘数规则

| 填写 | 结果 |
| --- | --- |
| 数量 5 | 随机抽 5 个视频，各复制一份 |
| 数量 5，乘数 3 | 按选中的乘数规则放进去 15 个文件 |
| 数量栏直接输入 5*3 | 自动拆成数量 5、乘数 3（也支持 5x3、5×3） |

表格上方可以切换三种乘数规则。点旁边的问号有图示，再点一下问号收起：

- 连续重复：抽 5 个不同的视频，每个连着放 3 份。
- 循环重复：抽 5 个不同的视频排成一批，整批放 3 遍。
- 分轮随机：一共抽 3 轮，每轮重新抽 5 个。同一轮里不重复，不同轮可能抽到同一个视频，也可能抽到新的。

文件夹里的先后顺序就是文件名的顺序，所以三种规则靠文件名来排：

| 规则 | 文件名 | 按名称排序后 |
| --- | --- | --- |
| 连续重复 | 第一份用原名，其余副本在后面加随机字符：开场1.mp4、开场1_k.mp4、开场1_7.mp4 | 同一个视频的几份挨在一起 |
| 循环重复 | 每个文件前面加两位轮次序号：01_开场1.mp4、01_开场2.mp4、02_开场1.mp4、02_开场2.mp4 | 第 1 遍排完才是第 2 遍 |
| 分轮随机 | 同样加轮次序号：01_开场1.mp4、01_开场2.mp4、02_开场1.mp4、02_开场5.mp4 | 第 1 轮排完才是第 2 轮 |

- 乘数不填或填 1 时，每个视频只复制一份，文件名不变。
- 循环重复和分轮随机时，同一批里没填乘数的分类也会加上「01_」，它们算在第 1 轮里。
- 带序号的视频程序认得出原名：以后再往同一个文件夹里抽，不会把同一个视频再抽一次。
- 副本的内容和原视频完全相同。乘数最多 99，一次最多放进去 10,000 个文件。

### 方案

经常用同一组参数时，点「方案」→「把当前数量保存为方案」，起个名字。方案会保存每个分类的数量、乘数和乘数规则，以后在「方案」里点一下就能填入。「管理方案」里可以重命名或删除。

### 用标签找分类

分类多了以后，可以给分类贴标签。点分类名称后面的「+ 标签」，点一下标签就贴上，再点一下取下，不用另外保存；也可以在这里直接新建标签。每个分类的标签会显示在名称后面。

贴过标签后，表格上方会出现标签栏：点一个标签，就只显示带这个标签的分类；可以点多个，带其中任意一个标签的分类都会显示。点「全部」恢复显示所有分类。已经填了数量的分类不会被隐藏。

- 标签只是帮忙找分类，不影响抽到哪些视频。
- 标签按分类文件夹的名称记录；在素材库里重命名会一起保留标签。在资源管理器里直接改名后，需要重新贴一次。
- 标签栏右边的齿轮可以改名、换颜色或删除标签；删除标签不会动分类和视频。


### 素材库

「素材库」页用来管理和核对素材：左边是素材根目录里的所有分类和各自的视频数，右边是选中分类里的视频。

**新建分类**：点左下角的「新建分类」，起个名字。程序会在素材根目录里新建一个同名文件夹。

**添加视频**：选中一个分类，点「添加视频」，选择一个或多个视频文件。

- 视频是复制进分类文件夹的，原文件保留在原处。
- 分类里已经有同名文件时会跳过，不会覆盖；不是视频的文件也会跳过。完成后会提示加了几个、跳过了哪些。
- 添加过程中可以取消，取消后这一次已经放进来的视频也会撤掉。
- 添加视频和抽取复制不能同时进行。

**查看视频**：

- 右上角可以切换「列表」和「图标」两种显示方式。
- 列表：点表头按文件名、大小或修改时间排序；鼠标移到一行上会弹出这个视频的预览画面。
- 图标：每个视频显示一张画面，下面是文件名和大小。
- 视频多的时候可以用「查找视频」。
- 双击视频或点播放按钮，用系统默认的播放器打开。
- 「打开文件夹」直接打开这个分类的文件夹；左下角可以打开素材根目录。
- 这里也可以给分类贴标签。

**缩略图**：预览画面第一次看到时生成一次，之后保存在数据文件夹里，再打开就不用等。

- 视频被删除、改名或替换后，对应的缩略图会自动清理。
- 少数格式（例如 .avi、.wmv、.flv，或电脑不支持的编码）生成不了画面，会显示一个胶片图标，不影响抽取和复制。
- 不需要的话可以在「设置 → 素材库」里关闭「缓存视频缩略图」，已经保存的缩略图会一并删除；关闭后素材库只有列表，不弹预览。

**分组和顺序**：左下角可以「新建分组」。分组标题有颜色、分类数和折叠箭头；抽取页也按同样的分组显示，“未分组”排在最后。拖动分组或分类可以调整顺序，把分类拖到另一组的标题上就能移入；右键或鼠标移上后点「…」也可以移动分类、修改分组名称和颜色、在分组里新建分类。删除分组只会把分类移到“未分组”，不会删除文件夹或视频。分组、顺序和折叠状态保存在程序数据里，素材盘暂时拔掉后仍会保留。

**重命名分类**：双击左侧分类名称，或右键点「重命名」。程序会修改文件夹名称，同时保留标签、方案里对应的参数和已填写的数量、乘数；历史记录仍显示当时的名称。

**删除分类**：右键或点「…」→「删除分类…」。

- 不勾选「同时删除分类里的 N 个视频」：分类从程序里移除，文件夹和视频留在磁盘上；完全空的文件夹会删除。被移除的分类不再参与抽取或方案填入。以后新建同名分类，就能恢复它和原来的标签。
- 勾选后：直接删除这个分类里的视频，不移到回收站，不能恢复；有视频时还会再确认一次。其他文件和子文件夹会保留。文件夹清空后会删除，否则留在磁盘上并从程序里隐藏分类。
- 程序会记住上次是否勾选，下次删除时按上次的选择显示。

单个视频的删除或改名仍在文件夹里操作，切回程序窗口会自动刷新。


## 四、规则

- 每个分类内随机抽取，不重复；不同批次可以抽到同一个视频。
- 视频保留原文件名和内容复制过去（用了乘数时文件名会加后缀或轮次序号，见上面的“乘数和乘数规则”），原素材不会被移动或修改。
- 同一批视频要放进同一个文件夹，所以会自动避开同名的视频：与其他分类抽中的视频同名的、与目标文件夹里已有文件同名的（大小写不同也算同名；文件夹里带轮次序号的视频按原名算）。可用的视频不够时会提示最多还能抽几个，不会覆盖任何文件。
- 支持的格式：.mp4 .mov .mkv .avi .wmv .flv .webm .m4v .mpeg .mpg .ts .mts .m2ts .3gp（按扩展名识别，不检查编码）。
- 复制前会检查目标磁盘的剩余空间。


## 五、清空旧视频

目标文件夹里已有视频时，右侧会出现「复制前清空这里的 N 个旧视频」。勾选后开始复制会先确认，再删除这些旧视频、放入新视频。

- 只删除这个文件夹里直接放着的视频；其他文件和子文件夹保留。
- 请在处理程序停止使用这个文件夹后再操作。
- 完成后这个选项会自动取消勾选。


## 六、复制的安全措施

- 先把全部视频复制到目标根目录里的临时文件夹（.video-picker-开头，已隐藏），全部成功后才一次性放进目标文件夹。
- 复制失败或取消时，撤销本次放入的视频，并恢复被清空的旧视频。
- 复制期间如果目标文件夹被其他程序改动，会停止并恢复，避免和处理程序冲突。
- 意外断电或强制结束程序时可能留下临时文件夹。下次打开会在左侧顶部提示，其中 old 子文件夹可能存有旧视频，确认后可以手动删除。


## 七、复制记录

「记录」页保存最近 50 次复制：时间、用的数量和乘数、放入的文件夹、每个视频的名称和大小。点「打开文件夹」可以直接打开当时的目标文件夹。

- 按这组参数再抽一次：把当时的数量、乘数和乘数规则填回抽取页，再点「抽取并复制」就是新的一批。
- 保存为方案：给这一次的参数起个名字固定下来，以后在抽取页的「方案」里一键填入。


## 八、设置

右上角齿轮图标：

- 窗口始终显示在最前面（右上角的图钉按钮也可以切换）
- 外观：跟随系统 / 浅色 / 深色
- 复制完成后自动打开目标文件夹
- 复制完成后：留在程序 / 最小化 / 退出程序；只在抽取复制成功后执行，添加视频不触发
- 下次打开时保留上次填写的数量
- 缓存视频缩略图（默认开启，见“素材库”）
- 打开数据文件夹

### 锁屏密码

在「设置 → 锁屏」里勾选「打开软件时需要输入 4 位密码」，设置一个 4 位数字密码。开启后：

- 每次打开软件先看到锁屏，输对密码才能使用。
- 顶栏会多一个锁的按钮，点一下可以随时锁定。
- 连续输错 5 次后需要等一会儿才能再试，再输错等待时间会加长，最长 10 分钟。
- 忘记密码时，在锁屏上点「忘记密码？」，输入购买时的授权码就可以关闭锁屏密码，之后在设置里重新设置。

锁屏只是防止别人随手打开软件，不会加密数据文件；数据文件夹里的内容和以前一样。


## 九、数据保存在哪里

    %APPDATA%\VideoRandomPicker\

- settings.json：选择过的文件夹和设置
- lock.json：锁屏密码的校验信息（不保存密码本身）；删除这个文件等于关闭锁屏密码
- tags.json：标签和每个分类贴的标签
- layout.json：分组、分类顺序、所属分组和隐藏状态
- history.json：复制记录
- presets.json：保存的方案
- thumbs 文件夹：视频缩略图的缓存，可以随时删除，需要时会重新生成
- window.json：窗口大小
- license.json：本机授权信息
- license-state.bin：本机授权保护状态

这些文件不会混进视频文件夹。卸载程序不会删除它们。

便携模式：在「视频分发工具.exe」所在的文件夹里新建一个名为 data 的文件夹，程序就会把数据保存在这里。
