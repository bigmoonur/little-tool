# 文本随机提取工具 使用说明

按分类保存素材（每行一条），抽取时为每个分类填写数量，程序随机抽取、打乱顺序后复制到剪贴板。

适用于 Windows 10 / 11（64 位）。


## 一、安装

两种方式任选一种：

- 安装版：双击「文本随机提取工具-版本号-安装包.exe」，按提示完成。不需要管理员权限，桌面和开始菜单会出现「文本随机提取工具」。
- 免安装版：直接双击「文本随机提取工具.exe」运行，可以放在任意文件夹。

第一次打开时如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

程序界面依赖 Windows 自带的 WebView2 组件（Windows 11 和更新过的 Windows 10 都已自带）。安装版会在缺少时自动安装；免安装版缺少时会提示下载。


## 二、激活

第一次打开时需要输入购买时获得的授权码，点「激活」。激活需要联网。

- 同一授权码在同一电脑上，两款工具共用设备名额；首次使用两款工具时分别输入一次授权码。
- 每台电脑激活一次，以后打开程序会自动联网验证，不用再输入；连续运行时每 24 小时复核一次。
- 暂时没有网络也能继续使用 7 天；超过 7 天没有联网验证，需要连上网络打开一次。
- 换电脑：先在旧电脑两款工具的「设置 → 解除本机授权」中都解除，再在新电脑输入同一个授权码。
- 一个授权码能激活几台电脑由卖家设定。提示「可激活电脑数已用完」时，先在旧电脑解除授权，或联系卖家。
- 「设置 → 授权」里可以看到授权码（部分隐藏）、有效期和本机名称。


## 三、添加素材

素材按「分类」保存。每个分类相当于以前的一个 TXT 文件，里面每一行是一条素材。

添加方式：

- 把 TXT 文件直接拖进窗口（可以一次拖多个）
- 点右上角「添加素材」，选择 TXT 文件或粘贴文本
- 在素材库里选中某个分类，点「添加素材」或「从 TXT 导入」

TXT 的编码会自动识别（UTF-8、GBK 都可以），空行和每行首尾的空格会自动去掉。

### 添加到哪里

添加时会让你选择去向，下方会实时显示「将新增多少条、跳过多少条重复」，确认后再添加。

导入 TXT 文件时：

- 每个文件一个分类（默认）：以文件名作为分类名。如果已经有同名分类，默认「追加」到已有分类，也可以改成「替换全部内容」或「另建新分类」。
- 全部添加到已有分类：所有文件的内容都加到选定的一个分类里。
- 合并成一个新分类：所有文件合并成一个新分类。

粘贴文本时：

- 已有分类：加到选定的分类末尾。
- 新建分类：填写名称，可选择放入哪个分组。

勾选「替换原有内容」时，会清空该分类原有的内容，只保留这次添加的内容（按钮会变成红色的「替换内容」）。

「跳过重复的行」默认开启：分类里已经有的内容、或这次添加中重复出现的内容都不会再加。

从旧版迁移：把原来素材文件夹里的 TXT 全部拖进窗口，选「每个文件一个分类」即可。


## 四、分组

分类多了以后可以用分组整理，例如「服装类」「配饰」。

- 素材库左下角「新建分组」
- 把分类拖到分组上，或在分类上点右键 →「移动到分组」
- 分组右边的「⋯」可以：在此分组中新建分类、重命名、换颜色、上移/下移、删除分组
- 删除分组时可以选择「只删除分组」（分类移到「未分组」）或「连同分类一起删除」
- 点分组标题可以折叠/展开，抽取页也一样；折叠的分组里填好的数量仍然有效


## 五、抽取

在「抽取」页为每个分类填写数量，然后点「抽取并复制」。结果会直接复制到剪贴板，可以马上粘贴。

| 填写 | 结果 |
| --- | --- |
| 数量 100 | 随机抽取 100 行 |
| 数量 25，每条重复 4 | 抽 25 条不同内容，每条连续重复 4 次，共 100 行 |
| 数量栏直接输入 25*4 | 同上，会自动拆成数量 25、重复 4（也支持 25x4、25×4） |
| 留空或 0 | 跳过这个分类 |

规则：

- 普通数量按行抽取。
- 重复次数大于 1 时，同一分类里完全相同的内容只算一条，保证抽到的内容各不相同。
- 所有分类抽到的内容会混合打乱；同一条内容的重复行始终连在一起。
- 一次最多输出 100,000 行，防止数量输错。
- 数量超过分类里的条数时，该行会变红并提示最多可以抽多少条。

键盘操作：

- 在数量栏按回车跳到下一个分类，最后一个分类按回车直接抽取（和以前的用法一样）
- Ctrl + 回车：随时抽取
- 方向键 上/下：在分类之间移动

抽取完成后右侧会显示结果预览，可以「复制」（再复制一次同一批）、「重新抽取」（按当前数量换一批）、「保存为 TXT」。

### 方案

经常用同一组数量时，点「方案」→「把当前数量保存为方案」。以后在「方案」里点一下就能填入这组数量。「管理方案」里可以重命名或删除。


## 六、抽取记录

「记录」页保存最近 30 次抽取结果。剪贴板被覆盖了也能在这里找回来：

- 复制 / 保存为 TXT
- 按这组数量再抽一次：把当时的数量填回抽取页


## 七、编辑素材

在「素材库」选中分类，右侧可以直接修改内容，每行一条。

- 修改后按 Ctrl + S 或点「保存」；切换分类、切换页面或关闭窗口时，如果有没保存的修改会提醒
- Ctrl + F 查找内容
- 「去除重复」删除重复的行
- 「导出 TXT」把分类保存为 TXT 文件
- 双击左侧分类名称可以重命名，右键有更多操作


## 八、撤销

删除分类、删除分组、保存修改、添加素材、去除重复之后，底部提示条上会有「撤销」按钮；提示消失后，在光标不在输入框里时按 Ctrl + Z 也能撤销刚才的这一步。


## 九、设置

右上角齿轮图标：

- 窗口始终显示在最前面（右上角的图钉按钮也可以切换）
- 复制成功后：保持窗口 / 最小化 / 关闭程序
- 外观：跟随系统 / 浅色 / 深色
- 下次打开时保留上次填写的数量
- 添加素材时默认跳过重复的行
- 导出备份 / 从备份恢复 / 打开数据文件夹
- 授权：查看授权码、有效期，解除本机授权


## 十、数据保存在哪里

素材自动保存在：

    %APPDATA%\MaterialPicker\

- library.json：全部分类、分组和方案
- history.json：抽取记录
- license.json：本机授权信息
- license-state.bin：本机授权保护状态
- backups\：自动备份（修改前保留最近 20 份）

卸载程序不会删除这些数据。换电脑时，在旧电脑「设置 → 导出备份」，在新电脑「设置 → 从备份恢复」。

便携模式：在「文本随机提取工具.exe」所在的文件夹里新建一个名为 data 的文件夹，程序就会把数据保存在这个 data 文件夹里，可以连同程序一起拷到 U 盘。


## 十一、快捷键

| 按键 | 作用 |
| --- | --- |
| 回车 | 抽取页：下一个分类；最后一个分类直接抽取 |
| Ctrl + 回车 | 抽取 |
| Ctrl + 1 / 2 / 3 | 切换到 抽取 / 素材库 / 记录 |
| Ctrl + S | 保存正在编辑的分类 |
| Ctrl + F | 在分类内容中查找 |
| Ctrl + Z | 撤销上一步 |
| Esc | 关闭弹窗 |
